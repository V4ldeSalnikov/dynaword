# Dynaword

[![PyPI](https://img.shields.io/pypi/v/dynaword)](https://pypi.org/project/dynaword/)
[![Python](https://img.shields.io/pypi/pyversions/dynaword)](https://pypi.org/project/dynaword/)
[![License: CC0](https://img.shields.io/badge/license-CC0--1.0-blue)](LICENSE)

Shared Python tooling for maintaining Dynaword text datasets. It validates data and dataset cards,
generates statistics and plots, and manages dataset versions.

Explore the [Dynaword collection on Hugging Face][collection].
